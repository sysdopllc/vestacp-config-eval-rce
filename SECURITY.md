# Security Policy

This repository is itself a security advisory (VESTACP-2026-001 /
GHSA-m2mc-xwq7-pw72) for the Vesta Control Panel.

## Reporting

For questions about this advisory, or to report related findings, contact:

- **security@sysdop.com** (Bryan Ramirez — SYSDOP LLC)

Please use coordinated disclosure for any new, unpublished finding: email the
details privately and allow reasonable time before public release. Findings in
*this* repository's content can be raised via a GitHub Security Advisory on
this repo or by email.

## Scope note

The advisory concerns the original, unmaintained VestaCP
(`github.com/serghey-rodin/vesta`). It is not a report against GitHub or any
third party hosting this repository.
